# sabri-recomendacoes

**Modo obrigatório:** somente leitura de dados externos. Esta Skill NÃO dá permissão para editar campanhas, cobrar mídia, publicar landing ou modificar configurações. A regra `CLAUDE.md` existente continua valendo.

1. Ler seção F do complemento e pedir prints/exportações de recomendações, opções autoaplicadas e histórico.
2. Identificar quais sugestões alteram palavras, segmentações, criativos, lances e possíveis efeitos comerciais.
3. Avaliar cada sugestão: ACEITAR / TESTAR / RECUSAR / SEM DADOS; evidência, custo/risco, reversibilidade e impacto plausível.
4. Não assumir viés malicioso do suporte nem seguir recomendação por nota de otimização.
5. Fornecer caminho para revisão humana; não ativar/desativar autoapply, bloquear representantes ou editar campanhas sem autorização delimitada.

## Saída
Inclua dados/fonte/período, fatos x inferências, tabela de ações, riscos, confiança, tarefas humanas e estado real de execução.
