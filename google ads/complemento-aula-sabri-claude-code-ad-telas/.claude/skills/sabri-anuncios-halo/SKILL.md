# sabri-anuncios-halo

**Modo obrigatório:** somente leitura de dados externos. Esta Skill NÃO dá permissão para editar campanhas, cobrar mídia, publicar landing ou modificar configurações. A regra `CLAUDE.md` existente continua valendo.

1. Consulte a matriz da seção C do arquivo principal. Confirmar serviços, regiões, preços e vantagens realmente oferecidos.
2. Pesquise dúvidas reais com fontes verificáveis em Google, fóruns, Reddit e avaliações (se disponível). Separe fato coletado de hipótese; não extrapolar de usuários isolados.
3. Monte `palavra/intenção → problema → benefício comprovável → prova → título → descrição → landing`.
4. Gere rascunhos criativos, selecione alternativas RSA com títulos até 30 caracteres e descrições até 90 caracteres conforme especificação atual a conferir, evitando repetição e não impondo preenchimento obrigatório de 15/4.
5. Faça auditoria de promessas e política de anúncios: NÃO clickbait, medo, urgência fictícia, provas inventadas ou uso não autorizado de marca.
6. Entregue tabela/csv pronta para REVISÃO; não publique, edite nem pause anúncios.

## Saída
Inclua dados/fonte/período, fatos x inferências, tabela de ações, riscos, confiança, tarefas humanas e estado real de execução.
